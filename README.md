# HLB 유니버스 기존 주소 연결

이 저장소는 기존 `https://hlbbusisup-creator.github.io/hlb-universe/` 주소를 유지하기 위한 작은 연결 페이지입니다. 실제 소스, 커밋 및 배포는 **[bhb2463-1/hlb-universe](https://github.com/bhb2463-1/hlb-universe)**에서만 관리합니다.

- `hlb-universe/index.html`은 새 계정의 최신 사이트를 전체 화면 iframe으로 표시합니다. 기존 주소창을 유지하고, 방문 공간과 제품 링크의 query/hash를 그대로 전달합니다.
- 화면이 열리지 않는 경우에 사용할 ‘새 창으로 열기’ 링크를 항상 제공합니다. iframe에는 자동재생 및 전체화면만 허용합니다.
- `404.html`은 예전 주소로 공유된 `/hlb-universe/` 하위 PDF·이미지 등 직접 링크만 같은 경로의 새 도메인으로 연결합니다. 다른 경로는 안내 화면을 표시합니다.
- 루트 주소는 `/hlb-universe/`로 연결됩니다. `.nojekyll`은 파일을 정적으로 게시하도록 합니다.

이 페이지에는 체험관 사본이 없으므로 실제 앱을 수정할 때 함께 복사하거나 정기 동기화할 필요가 없습니다. 기존 `hlbbusisup-creator/hlb-universe` 저장소를 재생성하지 않으므로 해당 Git 저장소 주소의 이전 리디렉션도 유지할 수 있습니다.

계정·원본 도메인이 바뀔 때만 이 연결 페이지의 목적지를 수정합니다. 일반적인 제품·전시관·기능 수정은 새 계정의 원본 저장소에 커밋합니다.
